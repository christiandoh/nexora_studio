## 🚀 Aperçu

**Nexora Studio** est un site vitrine premium pour un studio digital basé à Abidjan, spécialisé dans :

- 🤖 **Agents IA** — OpenCode, OpenClaw, Hermes Agent
- 🌐 **Sites web & Applications web** — Next.js, React, E-commerce
- 📱 **Applications mobiles** — Flutter, iOS & Android
- ⚡ **Automatisation IA** — Chatbots, Workflows, n8n
- 🎓 **Formation & Transformation IA** — Ateliers, Bootcamps

Le site est conçu avec des animations fluides (60fps), un thème clair/sombre, et une expérience utilisateur inspirée des interfaces PS5 et Netflix.

---

## 📦 Stack technique

| Technologie | Utilisation |
|---|---|
| **React 19** | Bibliothèque UI |
| **Vite 8** | Bundler & dev server |
| **React Router DOM 7** | Routage multi-pages |
| **Framer Motion 12** | Animations & transitions |
| **Lucide React** | Icônes professionnelles |
| **CSS personnalisé** | Design system, variables CSS, glassmorphism |
| **GitHub Pages** | Hébergement & déploiement |

### Fonctionnalités clés

- **🎨 Design system complet** — Variables CSS pour les thèmes dark/light, typographie Poppins
- **🖱️ Curseur custom** — Effet de traîne, glow au survol, désactivé sur tactile
- **🌓 Thème clair/sombre** — Persistance localStorage, toggle fluide
- **📱 Responsive** — Breakpoint 900px, grilles adaptatives
- **🎬 Animations avancées** — Scroll reveal, parallax 3D, glassmorphism, background immersif
- **🖼️ Section PS5/Netflix** — Cartes avec focus central, hover 3D, modal plein écran

## 🛠️ Développement

```bash
# Cloner le projet
git clone https://github.com/christiandoh/nexora_studio.git
cd nexora_studio

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Build production
npm run build

# Prévisualiser le build
npm run preview

# Déployer sur GitHub Pages
npm run deploy
```
